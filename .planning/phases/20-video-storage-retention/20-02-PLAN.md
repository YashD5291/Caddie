## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite `meeting_id` values → filesystem paths | `deleteMedia` builds paths from a DB value |
| App → `~/Library/Application Support/Caddie/audio/` | Deletes and enumerates the user's media files |
| Test host → real data directory | `make test` launches the real `AppState.initialize()` against the real DB and directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-04 | Information disclosure | `deleteMedia` | mitigate | Deletes `.mov` by meeting id regardless of `video_file`, so no screen recording outlives its meeting (D-09); the launch sweep is the safety net for any failed delete |
| T-20-05 | Tampering | `deleteMedia` path building | mitigate | `isSafeMeetingId` rejects empty ids and any id containing `/` or `..` before a path is built; covered by `testDeleteMediaRejectsPathTraversalIds` |
| T-20-06 | Tampering (self-inflicted data loss) | `cleanupOrphanedVideos` | mitigate | List-then-read ordering; skip on any ID-read throw (D-10); skip on an empty ID set with videos present (D-14); regular files with a `.mov` extension only, non-recursive, confined to the passed directory; never builds a path from a DB value |
| T-20-07 | Tampering | sweep racing a live recording | mitigate | Called synchronously in `initialize()` before `RecordingCoordinator` exists; acceptance criterion asserts it sits above the coordinator construction |
| T-20-08 | Tampering | tests mutating real user data | mitigate | All new tests pass `in: tempDir` (D-15); grep gate limits `audioDirectory` in `MediaFileTests` to the single default-path equality assertion |
| T-20-09 | Information disclosure | logs | mitigate | Logs filenames, counts, and error descriptions only, via `CaddieLogger.storage`; never file contents |
</threat_model>
