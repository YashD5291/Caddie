<objective>
Add the storage schema for linked video: a second GRDB migration `v2_add_video_columns` adding nullable `video_file` (filename only, mirroring `audio_file`) and `video_start_offset` (seconds from audio start to the first video frame, the STOR-04 anchor in the form Phase 21 playback needs), and thread both fields through the `Meeting` record.

Purpose: STOR-01 (video linked to the meeting row, never in FTS5) and the STOR-04 storage leg (anchor persisted with the meeting). This plan builds only the schema and model; 20-06 writes the values.
Output: one new migration, two new `Meeting` fields, and tests proving the upgrade path and FTS isolation.
</objective>
