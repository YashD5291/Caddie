<objective>
Persist the video link and the timing anchor, and verify the file after the engine finalizes it. One ordered event funnel per meeting (an `AsyncStream` fed by the engine's first-frame and finalize callbacks) links the row when the first frame lands. It then inspects the file on finalize, keeping a usable file and deleting an unusable one. Every path is keyed by meeting id, so late finalizes and meeting #2 cannot cross wires.

Purpose: STOR-01 (video linked to the meeting row) and the STOR-04 storage leg (anchor persisted), per D-05 (as amended: link early, verify after finalize), D-06, D-07, D-08, D-11, D-13. Link-early is the only design that keeps quit and crash partials linked with their anchor without a launch reconciliation pass.
Output: coordinator funnel plus `RecordingCoordinatorVideoStorageTests`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Engine queues → coordinator actor | First-frame and finalize events arrive from writerQueue / AVFoundation completion threads |
| Coordinator → user's media directory | Discard deletes `.mov` files; start-failure cleanup removes partials |
| Coordinator → meetings table | Link/unlink writes during and after recording |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
